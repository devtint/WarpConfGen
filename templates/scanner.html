Setup & Run Guide

  • 1
    Install Python (if needed)

    Open Command Prompt and type python. If it is not installed, Windows 10/11 will automatically redirect you to the Microsoft Store to install it. Alternatively, download it from python.org.

  • 2
    Open PowerShell or Terminal

    Open the folder containing your downloaded script in PowerShell or command prompt.

  • 3
    Install Required Libraries
    pip install colorama

    Note: Standard python libraries are pre-installed. Only colorama is optional for colored output.

  • 4
    Run the Scanner
    python warp_scanner.py

    To limit the scan size for a faster test, append --max-ips 200 to the command.

  • 5
    Copy Best Endpoint

    The script will print the results sorted by latency and save them to a JSON file. Copy the best working IP:Port address (e.g. 188.114.98.30:500).

Advanced Options (CLI Flags)

You can customize how the scanner behaves by adding these optional flags when running the command:

--max-ips <number> Recommended

Limits the number of scanned IPs (e.g. --max-ips 150). Use this to finish the scan much faster.

--workers <number>

Sets parallel threads (default: 20). Higher values scan faster but require more CPU and bandwidth.

--timeout <seconds>

Ping timeout per IP in seconds (default: 1.5). Increase this if your internet connection is very slow or unstable.

--top <number>

Sets how many top working results to show in the final summary table (default: 20).

What to do next?

Once the script finishes scanning, it will list the best working Cloudflare IP addresses. Return to the homepage, switch endpoint IP mode to Custom IP, enter the working address, and click Generate Config to get a working VPN profile.
